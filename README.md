## F10 completion contracts

[Frozen F10 v5 package](F10-v5/README.md) supports the IMRAD article Source Conditioned Completion Contracts in an LLM Agent Harness. Tag: f10-v5-artifact-r1. The snapshot includes the original Linux harness executable, experimental code, all four model outcomes and original traces, offline reproduction scripts, architecture documentation and the revised submission documents.

This repository remains private. The full Orion source is not publicly released. Repository access, binary availability, source rebuilding and numerical reproduction are distinct and documented in the package. No public deposit or DOI is claimed.

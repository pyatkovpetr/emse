# EMSE research artifacts

Publicly readable research-artifact repository for Petr A. Piatkov's EMSE submission.

## F10 completion contracts

[Frozen F10 v5 package](F10-v5/README.md) supports the IMRAD article *Source Conditioned Completion Contracts in a Language Model Agent Harness*. The frozen snapshot is identified by tag `f10-v5-artifact-r1`. It includes the original Linux harness executable, experimental code, all four model outcomes and original traces, offline reproduction scripts, architecture documentation, and the manuscript files prepared with that snapshot.

The repository is now public. The tag and release were created while access was private, so historical files at that tag may still describe the earlier access state. The later technical corrections submitted to EMSE on 28 September 2026 are separate from the frozen research snapshot.

Public access to these files does not release the full Orion source, grant a blanket open-source licence, or establish that the modified harness source can be rebuilt. The exact executable, available records, reproduction steps, and third-party rights are documented in the package. No DOI or immutable repository deposit is claimed.
